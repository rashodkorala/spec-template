# Decisions (ADRs)

One file per decision: `NNNN-short-title.md`, numbered in order, never renumbered.
A superseded decision stays, marked `Superseded by NNNN`.

Use one for: approved platform differences, contract changes, product rules, and anything an agent might otherwise "fix".

Template: `_template.md`.
